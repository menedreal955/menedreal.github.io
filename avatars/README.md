# Папка аватарок магазинов (Instagram Avatars)

Сюда можно просто сохранять аватарки магазинов из Instagram!
Название файла должно совпадать с логином инстаграма магазина:

Например:
- `asxa_parfume.jpg`
- `gas_servis_.jpg`
- `dim_i_myaso95.jpg`
- `vay_zhalyuzy.jpg`
- `mega_argun.jpg`
- `toyota_razbor17.jpg`
- `chaban_gipermarket.jpg`

Приложение автоматически найдет картинку по юзернейму инстаграма и покажет в карточке магазина!
Если файла нет — приложение сгенерирует стильную иконку в фирменном градиенте Instagram.
