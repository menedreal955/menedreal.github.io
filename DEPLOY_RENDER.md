# Backend Telegram-бота — публикация на Render

Frontend проекта остаётся на Cloudflare Pages. Backend находится в папке `backend/`.

## Что добавлено

- `/start` отправляет приветствие и inline-кнопку «Открыть каталог».
- `/help` показывает команды.
- `/id` показывает Telegram ID пользователя (нужен для `ADMIN_ID`).
- `/api/applications` принимает заявки из Mini App.
- Сервер проверяет подпись Telegram `initData`, а не доверяет `initDataUnsafe`.
- Заявка отправляется администратору с кнопками «Принять» и «Отклонить».
- При выборе решения бот пытается уведомить пользователя в личном чате.
- `/health` — проверка доступности backend.

## 1. Получить Telegram ID администратора

1. Временно запусти бота с новым backend после деплоя (или воспользуйся `/id`).
2. Открой своего бота и отправь `/start`, затем `/id`.
3. Скопируй числовой Telegram ID. Он понадобится в переменной `ADMIN_ID` на Render.

Важно: пользователь-администратор должен хотя бы один раз открыть бота и нажать Start, иначе бот не сможет написать ему первым.

## 2. Создать Web Service на Render

1. Открой https://dashboard.render.com/.
2. Нажми **New → Web Service**.
3. Подключи GitHub и выбери репозиторий с проектом.
4. Укажи настройки:
   - **Runtime:** Node
   - **Root Directory:** `backend`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Health Check Path:** `/health`
5. Выбери тариф. Для постоянной работы бота нужен сервис, который не засыпает; учитывай актуальные ограничения и цену тарифа Render.
6. Создай Web Service и дождись первого успешного деплоя. Render назначит URL, например `https://instashop-backend.onrender.com`.

Если Render не видит `backend/package.json`, проверь, что `backend/` находится в корне выбранного GitHub-репозитория. Если репозиторий содержит дополнительную верхнюю папку `instashop/`, Root Directory должен быть `instashop/backend`.

## 3. Добавить Environment Variables на Render

В настройках сервиса открой **Environment → Add Environment Variable** и добавь:

| Key | Value |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_ID` | Числовой Telegram ID администратора |
| `FRONTEND_URL` | Полный HTTPS-адрес Cloudflare Pages, без завершающего `/` |
| `WEBHOOK_SECRET` | Случайная длинная строка из букв и цифр, минимум 32 символа |

Не добавляй токен в `config.js`, `app.js` или другие frontend-файлы. Он должен храниться только в Environment на Render.

После сохранения переменных Render перезапустит сервис. Backend сам зарегистрирует webhook по адресу Render и команды бота.

## 4. Прописать URL backend во frontend

Открой `config.js` в корне проекта и замени:

```js
window.INSTASHOP_API_URL = "https://YOUR-BACKEND.onrender.com";
```

на фактический URL своего Render Web Service, например:

```js
window.INSTASHOP_API_URL = "https://instashop-backend.onrender.com";
```

Сохрани файл, отправь изменения в GitHub и дождись обновления Cloudflare Pages.

## 5. Настроить кнопку меню в Telegram

В @BotFather:

1. `/setmenubutton`
2. Выбери своего бота.
3. Название: `Открыть каталог`.
4. URL: адрес Cloudflare Pages.

Кнопка в меню и inline-кнопка в сообщении `/start` — разные элементы. Backend отправляет inline-кнопку автоматически после `/start`.

## 6. Проверка

1. Открой `https://ТВОЙ-BACKEND.onrender.com/health`. Должен вернуться JSON `{"ok":true,...}`.
2. Открой бота и отправь `/start`. Бот должен прислать приветствие и кнопку «Открыть каталог».
3. Нажми кнопку и открой форму «Добавить магазин».
4. Отправь тестовую заявку.
5. Проверь, что администратор получил сообщение с кнопками «Принять» и «Отклонить».
6. Нажми одну из кнопок и проверь уведомление пользователя.

## Важные ограничения первой версии

- Заявки доставляются администратору в Telegram, но отдельная база истории заявок не подключена.
- Антиспам-лимит (одна заявка на пользователя за 30 секунд) хранится в памяти процесса и сбрасывается при перезапуске.
- Если пользователь отправляет заявку из обычного браузера, старый сценарий с открытием чата `@Menedreal` сохраняется. Отправка через API и серверная проверка Telegram доступны при запуске внутри Telegram Mini App.
- Кнопки решения заявки не являются автоматической публикацией магазина в каталоге. После одобрения данные магазина нужно добавить в `data/shops.js` и опубликовать frontend.
- Для реальной обработки платежей и автоматического управления VIP/баннерами понадобится отдельная интеграция оплаты и постоянное хранилище.
