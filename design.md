# Дизайн-система: Telegram Mini App — Каталог Instagram-магазинов

## 1. Концепция и визуальный стиль
- **Стиль**: Чистый, современный светлый интерфейс (Clean Light UI), оптимизированный под экраны смартфонов внутри Telegram.
- **Ощущение**: Быстрый нативный справочник. Никакой визуальной перегруженности, мгновенный отклик кнопок, крупные области нажатия (min 44px).

## 2. Цветовая палитра
- **Фон приложения (Background)**: `#F8FAFC` (мягкий светлый оттенок).
- **Фон карточек (Card Surface)**: `#FFFFFF` с мягкой тенью `0 2px 8px rgba(0,0,0,0.04)`.
- **Основной текст (Primary)**: `#0F172A` (глубокий графитовый, максимальная контрастность и читаемость).
- **Вторичный текст (Secondary / Muted)**: `#64748B` (описания, адреса, теги).
- **Рамки / Бордеры**: `#E2E8F0`.
- **Акцентные цвета каналов связи**:
  - **Instagram**: Градиент `#E1306C` -> `#F77737` (фирменная кнопка перехода в профиль).
  - **WhatsApp**: `#25D366` (зеленый для чата в один клик).
  - **Telegram**: `#2AABEE` (фирменный голубой цвет).
  - **2GIS / Карта**: `#00B259` или нейтральный темный `#334155`.

## 3. Компоненты интерфейса
1. **Шапка (Header)**:
   - Заголовок с названием города / проекта.
   - Поле поиска (input) с иконкой лупы и кнопкой очистки.
   - Фильтр по районам города (выпадающий список / чипсы).
2. **Вертикальная колонка категорий (Left Categories Rail)**:
   - Расположена слева вертикально, ширина 86px, фиксирована (sticky) при скролле.
   - Кнопка-чипс: крупная иконка сверху + подпись снизу (10.5px, плотный межбуквенный интервал, длинные слова помещаются в одну строчку).
   - Активная категория подсвечивается темным фоном с белым текстом (`#0F172A`).
3. **Карточка магазина (Shop Card)**:
   - Расположена в правой колонке (`content-column`).
   - Аватар магазина (скругленный квадрат `border-radius: 12px`, 52x52px).
   - Название магазина (жирный 16px) + бейдж категории.
   - **VIP-карточка (Монетизация №1)**: золотая рамка `#F59E0B`, мягкий теплый фон, бейдж `🔥 ТОП ВЫБОР`.
   - **Скидка и промокод (Монетизация №5)**: изумрудная плашка `🎁 Скидка по промокоду`.
   - Кнопки быстрого действия (Instagram, WhatsApp с предзаполненным промокодом).
4. **Рекламный промо-баннер (Монетизация №2)**:
   - Расположен над списком магазинов, темный фон с фото, бейдж акции и кнопка перехода.
5. **Форма заявки на размещение (Монетизация №4)**:
   - Модальное окно с выбором тарифов (Базовый, VIP, Баннер) и быстрой отправкой в Telegram.
6. **Модальное окно / Нижняя шторка (Bottom Sheet)**:
   - Полная информация, точный адрес, кликабельная ссылка на 2GIS / Яндекс Карты, копирование контактов, прямые кнопки связи.

## 4. Адаптивность и Telegram WebApp SDK
- Корректная обработка `Telegram.WebApp.expand()` для открытия во весь экран.
- Учет безопасных зон Telegram (safe areas).
- Плавные анимации нажатий (`active:scale-98`).
